# Tongal

> Tongal is a Santa Monica, California creative content platform ("your studio on demand") that connects brands and studios with a global community of writers, directors, and production companies. Founded in 2009 by James DeJulio, Rob Salvatore, and Mark Burrell and backed by Insight Partners (2012), Tongal runs branded video, advertising, and original-content projects through ideation, pitch, and production phases for clients such as LEGO, Procter & Gamble, Unilever, NASA, and Lucasfilm. Tongal publishes no public developer API: api.tongal.com exists only as the private backing API for the tongal.com web app (CORS-locked to tongal.com, session-cookie auth, no published spec or discovery surface).

## API surface

- No public API, developer portal, or API documentation is published.
- api.tongal.com: private web-app backing API only (no OpenAPI, no /.well-known discovery, all probed paths 404).
- api.tongal.com/api/graphql: private GraphQL endpoint used by the web app; introspection is disabled (INTROSPECTION_DISABLED) and CORS is locked to tongal.com.
- No packages on npm, PyPI, or other public registries.
